# TempCompass 数据集使用指南

## 项目概述

TempCompass 是一个视频理解数据集，专注于测试模型对视频中时序信息的理解能力。

## 数据集结构

### 目录结构
```
Tempcompass/
├── videos/                          # 视频文件目录（410个视频）
│   ├── 1034419625.mp4              # 原始视频
│   ├── 1034419625_reverse.mp4      # 反向视频
│   ├── 1034419625_concat_0.mp4     # 拼接视频
│   └── ...
├── test-00000-of-00001 (1).parquet # 数据集标注文件
├── tempcompass_full.json           # 完整JSON格式（已生成）
├── tempcompass_sample.json         # 示例JSON（已生成）
└── read_tempcompass.py             # 数据读取脚本
```

### 数据统计
- **总样本数**: 1,580 条
- **唯一视频数**: 410 个
- **数据维度**: 5 个类别

## 数据字段说明

每条数据包含 4 个字段：

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `video_id` | string | 视频文件ID（不含扩展名） | "1034419625" |
| `question` | string | 多选题问题文本 | "What is the man doing in the video?\nA. dunking..." |
| `answer` | string | 正确答案 | "A. dunking a basketball" |
| `dim` | string | 问题维度类别 | "action", "direction", "speed"等 |

## 数据维度分类

数据集包含 5 个测试维度：

| 维度 | 样本数 | 说明 |
|------|--------|------|
| `action` | 338 | 动作识别（如：扣篮、运球） |
| `direction` | 335 | 方向理解（如：从左到右、靠近相机） |
| `speed` | 317 | 速度判断（如：快速、缓慢） |
| `order` | 302 | 时序顺序（如：先后关系） |
| `attribute_change` | 288 | 属性变化（如：物体状态改变） |

## 如何读取数据

### 方法 1：使用 Python 脚本（推荐）

使用 swift conda 环境：

```bash
cd Tempcompass
conda run -n swift python read_tempcompass.py
```

这将生成：
- `tempcompass_full.json` - 完整数据集（1,580条）
- `tempcompass_sample.json` - 示例数据（100条）

### 方法 2：使用 pandas 直接读取

```python
import pandas as pd

# 读取 parquet 文件
df = pd.read_parquet("test-00000-of-00001 (1).parquet")

# 查看基本信息
print(df.head())
print(df.info())

# 按维度筛选
action_data = df[df['dim'] == 'action']
print(f"Action 维度样本数: {len(action_data)}")

# 获取特定视频的所有问题
video_questions = df[df['video_id'] == '1034419625']
```

### 方法 3：直接读取 JSON

```python
import json

with open('tempcompass_full.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# 遍历数据
for item in data[:5]:
    print(f"Video: {item['video_id']}")
    print(f"Question: {item['question']}")
    print(f"Answer: {item['answer']}")
    print(f"Dimension: {item['dim']}")
    print("-" * 80)
```

## 视频文件命名规则

1. **原始视频**: `{video_id}.mp4` （如：1034419625.mp4）
2. **反向视频**: `{video_id}_reverse.mp4` （用于测试方向理解）
3. **拼接视频**: `{video_id}_concat_{n}.mp4` （用于测试时序顺序）
4. **组合视频**: `{video_id1}_{video_id2}_{n}.mp4`

```python
# 获取视频路径
```


## 注意事项

1. Parquet 文件名包含空格和括号，在命令行中使用时需要正确转义
2. 部分视频有多个变体（原始、反向、拼接），用于测试不同的时序理解能力
3. 每个视频可能对应多个问题，测试不同的维度
4. JSON 文件已经生成，可以直接使用，无需重复转换

## 数据集来源

根据 README 信息，这是一个多任务视频理解数据集，包含：
- caption_matching: 1,503 样本
- captioning: 2,004 样本
- multi-choice: 1,580 样本（当前文件）
- yes_no: 2,453 样本

当前的 parquet 文件对应的是 **multi-choice** 任务。
